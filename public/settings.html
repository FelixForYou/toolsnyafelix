Deploy SSH backend

  1. Upload/extract project ke VPS/Pterodactyl.
  2. Jalankan npm install.
  3. Isi environment.
  4. Startup: npm start.
  5. Proxy domain HTTPS ke port 3000 dan teruskan WebSocket.
SSH membutuhkan proses Node persistent + WebSocket + akses TCP 22. Vercel serverless tidak menyediakan model koneksi ini untuk terminal SSH interaktif.

Security checklist

Karena dashboard terbuka langsung, batasi ALLOWED_SSH_HOSTS, gunakan HTTPS, dan lindungi domain dengan Cloudflare Access/WAF jika web bersifat publik.
